There are many ways in which we can hijack a Python library. Much depends on the script and its contents itself. However, there are three basic attack vectors where hijacking can be used:

1. `Insecure Write Permissions`
2. `Python Library Search Path`
3. `PYTHONPATH Environment Variable`

## Insecure Write Permissions
- Any of the python modules may have write permissions set for all users by mistake.
- Edit that module; insert commands or functions; run the script as root via sudo.

#### Checking sudo privileges
```python
sudo -l
```
- If we find a python script that we can run as root without a password, check its permissions : 
```python
ls -l mem_status.py
```
- Check if we have write permissions on this file
- If not read the file and see what modules the script is using

```python
grep -r "def virtual_memory"
#virtual_memory is the function from the imported module that the script was calling
```
- Check the permissions of this file to see if we have write permissions. Inject our code right at the beginning of the function.
- Just place a python reverse shell payload there and then run it :
	```python
	sudo /usr/bin/python3 ./mem_status.py
	```

## Python Library Search Path
- Each python version has a specified order in which libraries are searched and imported from.
- This is based on the priority system, paths higher in the list take priority over the ones lower in the list.

**command to see this :
```python
python3 -c 'import sys; print("\n".join(sys.path))'
```

To be able to use this variant, two prerequisites are necessary.

1. The module that is imported by the script is located under one of the lower priority paths listed via the `PYTHONPATH` variable.
2. We must have write permissions to one of the paths having a higher priority on the list.

- For example, lets consider that the script `mem_status.py` that we found earlier to have access to fun as sudo without requiring password imported the psutil module.
- Check the default installation location of pssutil by this command :
```python
pip show psutil
```
- Then check if any directory in the PYTHONPATH hyrarchically about psutils installation directory is writable.

```python
ls -la /usr/lib/python3.8
#Voila! It had write permissions
```
**Now we can just create a new `psutil.py` file within the python3.8 directory. Ensure that the module that we create has the same name as the import as well have the same function with the correct number of arguments passed to it as the function we are indending to hijack.**

- Then place a payload (can be a reverse shell) within the function and then execute our `mem_status.py` script as root:
```python
sudo /usr/bin/python3 mem_status.py
```
