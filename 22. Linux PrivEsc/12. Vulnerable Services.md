# Vulnerable Services - Privilege Escalation (Screen 4.5.0)

## Concept
- Misconfigured or vulnerable services running as **root** can be abused for **Privilege Escalation (PE)**.
- Always enumerate service versions after gaining initial access.

---

# GNU Screen 4.5.0 Privilege Escalation

## Vulnerability
- **Affected Version:** GNU Screen **4.5.0**
- **Issue:** Missing permission check when opening log files.
- **Impact:**
  - Create or overwrite files as **root**.
  - Overwrite `/etc/ld.so.preload`.
  - Load a malicious shared library.
  - Gain a **root shell**.

---

## Check Version

```bash
screen -v
```

Example:

```text
Screen version 4.05.00 (GNU) 10-Dec-16
```

---

## Exploitation Flow

1. Confirm vulnerable version.
2. Create malicious shared library (`libhax.so`).
3. Create SUID root shell binary (`rootshell`).
4. Abuse Screen logging to overwrite:

```text
/etc/ld.so.preload
```

5. Trigger Screen.
6. Shared library executes as root.
7. SUID bit is added to `rootshell`.
8. Execute:

```bash
/tmp/rootshell
```

9. Root shell obtained.
