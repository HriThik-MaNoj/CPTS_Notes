## Gaining Situational Awareness
 Typically we'll want to run a few basic commands to orient ourselves:
 - `whoami`
 - `id`
 - `hostname`
 - `ifconfig` or `ip a`
 - `sudo -l`
- `cat /etc/os-release`
- `echo $PATH`
- `uname -a`
- `lscpu` : Additional information about the CPU type/version
- `cat /etc/shells`

**Gaining awareness about the drives and shares on the system :** 
- `lsblk` : enumerate information about block devices on the system (hard disks, USB drives, optical drives, etc.)

- `lpstat`: Find information about printers attached to the system
- `cat /etc/fstab`

- `route` or `netstat -rn` : Check out the routing table
- `arp -a` : check arp table to see what other hosts the target has been communicating with


#### Existing Users
```python
cat /etc/passwd
```

#### Existing Groups
```python
cat /etc/group
```
**Listing members of groups :** 
```python
getent group sudo
```

#### Check for low hanging fruits
- Like config files and other files that may contain sensitive information
- If usernames,passwords found, use it against all the users present on the system. Password re-use is common

#### All Bash scripts 
```python
find / -name *.sh 2>/dev/null | xargs cat | grep "HTB"
```
#### All Hidden Files
```python
find / -type f -name ".*" -exec ls -l {} \; 2>/dev/null | grep htb-student
```

#### All Hidden Directories
```python
find / -type d -name ".*" -ls 2>/dev/null
```

#### Temporary Files
- `/tmp` : stores data for 10 days, data doesn't survive reboots
- `/var/tmp` : 30 days, survives

```python
ls -l /tmp /var/tmp /dev/shm
```
