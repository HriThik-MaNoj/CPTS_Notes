## Gaining Situational Awareness
 Typically we'll want to run a few basic commands to orient ourselves:
 - `whoami`
 - `id`
 - `hostname`
 - `ifconfig` or `ip a`
 - `sudo -l`
- `cat /etc/os-release`
- `echo $PATH`
- `uname -a`
- `lscpu` : Additional information about the CPU type/version
- `cat /etc/shells`

**Gaining awareness about the drives and shares on the system :** 
- `lsblk` : enumerate information about block devices on the system (hard disks, USB drives, optical drives, etc.)

- `lpstat`: Find information about printers attached to the system
- `cat /etc/fstab`

- `route` or `netstat -rn` : Check out the routing table
- `arp -a` : check arp table to see what other hosts the target has been communicating with
