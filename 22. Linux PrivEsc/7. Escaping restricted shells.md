# Escaping Restricted Shells

## What is a Restricted Shell?
A shell that limits what a user can do — restricts commands, directories, or environment changes. Used to sandbox untrusted/limited-privilege users (contractors, partners, specific-purpose accounts).

## Common Types
| Shell | Full Name | Restricts |
|---|---|---|
| `rbash` | Restricted Bourne Shell | Changing dirs, modifying env vars, running commands outside allowed dirs |
| `rksh` | Restricted Korn Shell | Running commands outside dirs, creating/modifying shell functions, modifying shell env |
| `rzsh` | Restricted Z Shell | Running scripts, defining aliases, modifying shell env |

> [!note] Real-world use case
> Orgs tier access by trust level:
> - External partners → `rbash` (e.g. email/file sharing only)
> - Contractors → `rksh` (more flexibility, e.g. DB/web servers)
> - Employees → `rzsh` (most flexibility, still restricted)

## Escape Techniques

### 1. Command Injection
If a restricted shell only allows a binary (e.g. `ls`) with limited args, inject a command via subshell execution inside the allowed argument.

```bash
ls -l `pwd`
```
`pwd` isn't directly allowed, but runs because it's nested inside the `ls` argument.

### 2. Command Substitution
Use shell substitution syntax (backticks `` `cmd` `` or `$(cmd)`) to sneak in execution of an otherwise-blocked command.

### 3. Command Chaining
Use shell metacharacters to run a second, unrestricted command alongside an allowed one:
- `;` → sequential
- `|` → pipe
- `&&` / `||` → conditional

### 4. Environment Variable Manipulation
If the shell relies on env vars (e.g. `PATH`, or a var defining allowed execution dir), modifying/overwriting it can redirect execution outside the intended restriction.

### 5. Shell Functions
If function definition is permitted, define a function that wraps/executes a disallowed command, then call the function name instead of the raw command.

---

## Quick Reference — Core Idea
> Restricted shells blocklist specific commands/paths, not the underlying shell **features** (substitution, chaining, env, functions). Escapes generally abuse those features to smuggle execution past the blocklist.
