`Netfilter` is a Linux kernel module that provides, among other things, packet filtering, network address translation, and other tools relevant to firewalls.
 Netfilter — Linux Kernel

  │ Note: Netfilter is the kernel-level framework behind firewalling (packet filtering, NAT). Programs like iptables/arptables are just front-ends
  to its hook system.

  What it does

  - Linux kernel module that controls/regulates network traffic at the packet level
  - Executes packet-filter modules on receive/send; they intercept & manipulate packets
  - 3 main functions:
    1. Packet defragmentation
    2. Connection tracking
    3. Network address translation (NAT)
  - All IP packets are checked by Netfilter before being forwarded to the target app

  Why old kernels persist in production

  - Companies run preconfigured distros tuned to their software ("dynamic basis" hard to replace)
  - Replacing requires adapting system↔app, which is costly & time-consuming
  - Containers/VMs still sit on the host kernel → container breakout is a real path to privesc
