## Enumeration
- When we get an initial shell access to a host, we need to check the following things  :
	- `OS Version`
	- `Kernel Version`
	- `Running Services`
	- `Installed Packages and Versions`
	- `Logged in Users`
	- `User Home Directories` : Are otehr user's home directories accesssible?
	- `configuration files` : such as .conf or .config for usernames, passwords and other secrets
	- `Readable Shadow File
	- `Password Hashes in /etc/passwd`
	- `Cron Jobs` : ls -la /etc/cron.daily/
	- `Unmounted File Systems and Additional Drives`: lsblk
	- `SETUID and SETGID Permissions` : Binaries are set with these permissions to allow a user to run a command as root, without having to grant root-level access to the user.
	- `Writeable Directories` : discover which directories are writeable if you need to download tools to the system. You may discover a writeable directory where a cron job places files, which provides an idea of how often the cron job runs and could be used to elevate privileges if the script that the cron job runs is also writeable.
	- `Find Writable Files`

#### List Current Processes
```python
ps aux | grep root
```
#### List Current Terminal-Attached Processes
```python
ps au
```

#### Home Directory Contents
```python
ls /home
```
- We can check for files like `.bash_history` and `SSH Keys`

#### SSH Directory Contents
```python
ls -l ~/.ssh
```

#### Bash History
```python
history
```

#### Sudo Privileges
```python
sudo -l
```

#### Find Writable Directories
```python
find / -path /proc -prune -o -type d -perm -o+w 2>/dev/null
```

#### Find Writable Files
```python
find / -path /proc -prune -o -type f -perm -o+w 2>/dev/null
```
