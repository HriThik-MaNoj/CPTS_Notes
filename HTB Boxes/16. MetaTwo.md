- we checked the `.config` file and it was empty.
- After more research we determined that we need to crack the key using john
```python
sed -n '/BEGIN PGP PRIVATE KEY BLOCK/,/END PGP PRIVATE KEY BLOCK/p' .keys > /tmp/priv.key
gpg2john /tmp/priv.key > /tmp/priv.hash
john --wordlist=/usr/share/wordlists/rockyou.txt /tmp/priv.hash
john --show /tmp/priv.hash
```
