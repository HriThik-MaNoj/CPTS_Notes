> Enumeration is the key to `privilege escalation` . when we gain initial access, it is vital to gain situational awareness and uncover details relating the OS version, patch level, installed software, current privileges, group memberships and more.

- This [Windows commands reference](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/windows-commands) is very handy for performing manual enumeration tasks.

## Key Data Points
`OS name`
`Version`
`Running Services` : Knowing what services are running on the host is important, especially those running as `NT AUTHORITY\SYSTEM` or `administrator-level` account.

## System Information

#### Tasklist
- can give us an idea of what applications are currently running on the system
```python
tasklist /svc
```

#### Display All Environment Variables
- One of the most overlooked variables is `PATH`
- If the folder placed in the `PATH` is writeable by your user, it may be possible to perform DLL injection against other applications.
- **when running a program, windows looks for that program in the CWD first and then from the path going Left -> Right. If custom path is placed on the left (before C:\Windows\Sysem32), It is much more dangerous than on the right.**

- In addition to `PATH`, `set` command can also give useful info like `Home Drive`. In enterprises, it will often be a fileshare and the fileshare can contain other directories that can be accessed.
- If a file is placed in `USERPROFILE\AppData\Microsoft\Windows\Start Menu\Programs\Startup`, when the user logs into a different machine, this file will execute.

```python
set
```

#### View Detailed Configuration Information
`systeminfo` command will show if the box has been patched recently and if it is a VM.

#### Patches and Updates
- If `systeminfo` doesn't display hot fixes, they may be queriable with WMI using the WMI - Command binary with [QFE (Quick Fix Engineering)](https://docs.microsoft.com/en-us/windows/win32/cimwin32prov/win32-quickfixengineering) to display patches.
- we can also use `Get-HotFix | ft -AutoSize` command in powershell to do the same.

#### Installed Programs
`WMI` Can also be used to display installed software.
```python
wmic product get name
```
Powershell alternative :
```python
Get-WmiObject -Class Win32_Product | select Name, Version
```
