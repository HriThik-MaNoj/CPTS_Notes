# Sticky Notes Passwords

- Windows **Sticky Notes** stores notes in a SQLite database.
    
- Always check it for **passwords, credentials, usernames, and sensitive information**.
    

## Database Location

```text
C:\Users\<user>\AppData\Local\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState\plum.sqlite
```

## Find Sticky Notes DB

```powershell
cd "C:\Users\<user>\AppData\Local\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState"
ls plum.sqlite*
```

Copy all related files:

```text
plum.sqlite
plum.sqlite-shm
plum.sqlite-wal
```

## Query with SQLite

Open the database using **DB Browser for SQLite** and query the `Note` table:

```sql
SELECT Text FROM Note;
```

Look for interesting data such as:

```text
password
passwd
username
cred
root:
admin
```

## PowerShell — PSSQLite

```powershell
Set-ExecutionPolicy Bypass -Scope Process

Import-Module .\PSSQLite.psd1

$db = 'C:\Users\<user>\AppData\Local\Packages\Microsoft.MicrosoftStickyNotes_8wekyb3d8bbwe\LocalState\plum.sqlite'

Invoke-SqliteQuery -Database $db -Query "SELECT Text FROM Note" | ft -wrap
```

## Quick Extraction with `strings`

After downloading the database files to the attack machine:

```bash
strings plum.sqlite
strings plum.sqlite-wal
strings plum.sqlite-shm
```

> **Important:** Check `plum.sqlite-wal` as well. It may contain recent or deleted Sticky Notes data.

## Key Takeaway

**Always enumerate Sticky Notes DB files during Windows credential hunting.**
