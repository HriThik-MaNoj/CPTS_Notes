- Members of this group are allowed to administer windows servers without needing assignment of Domain Admin Privileges.
- Highly privileged group that can log in locally to servers, including Domain Controllers.
- Membership of this group confers the powerful `SeBackupPrivilege` and `SeRestorePrivilege` privileges and the ability to control local services

#### Querying the AppReadiness Service
- We can confirm that this service starts as system using the sc.exe utility

```python
sc.exe qc AppReadiness
```

#### Checking Service Permissions with PsService
- used to check permissions of the service. [PsService](https://docs.microsoft.com/en-us/sysinternals/downloads/psservice)
- similar to sc utility and can display service status and configurations and allow us to start, stop, pause, resume and restart services both locally and on remote hosts.
```python
c:\Tools\PsService.exe security AppReadiness
```
- we can check if the Server Operators group has `SERVICE_ALL_ACCESS` access right, which can give us full control over the service.

#### Checking Local Admin Group Membership

#### Modify the Service Binary path
- change binary path to execute a command which adds our current user to default local administrators group.
```python
sc.exe config AppReadiness binPath= "cmd /c net localgroup Administrators server_adm /add"
```
