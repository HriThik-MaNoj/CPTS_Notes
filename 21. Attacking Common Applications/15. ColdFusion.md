> ColdFusion is a programming language and a web application development platform based on Java.

# ColdFusion - Discovery & Enumeration (CPTS)

## What is ColdFusion?

- Java-based web application platform.
- Uses **CFML (ColdFusion Markup Language)**.
- Common file extensions:
  - `.cfm`
  - `.cfc`

---

# Common Default Ports

| Port | Purpose |
|------|---------|
| 80 | HTTP |
| 443 | HTTPS |
| **8500** | ColdFusion (default, biggest indicator) |
| 5500 | Server Monitor |

> **8500** is a strong indicator of ColdFusion.

---

# Enumeration

## 1. Port Scan

```bash
nmap -p- -sC -sV <IP>
```

Look for:

```
8500/tcp open
```

---

## 2. Browse Port 8500

```
http://<IP>:8500
```

Common directories:

```
/CFIDE/
/cfdocs/
```

---

## 3. Check Default Paths

```
/CFIDE/
/CFIDE/administrator/
/CFIDE/adminapi/
/CFIDE/install.cfm
/cfdocs/
/Application.cfm
```

The Administrator page often reveals the exact ColdFusion version.

---

## 4. Look for CFML Files

```
index.cfm
login.cfm
Application.cfm
adminapi.cfc
```

Extensions:

- `.cfm`
- `.cfc`

---

## 5. HTTP Headers

Possible indicators:

```
Server: ColdFusion
X-Powered-By: ColdFusion
```

---

## 6. Error Messages

ColdFusion errors may reveal:

- Version
- File paths
- CFML tags
- Stack traces

Example:

```
Invalid request of Application.cfm
```

# Quick Checklist

- [ ] Scan ports (`nmap -sV`)
- [ ] Is **8500** open?
- [ ] Visit `http://IP:8500`
- [ ] Look for `/CFIDE/`
- [ ] Look for `/cfdocs/`
- [ ] Check `/CFIDE/administrator`
- [ ] Look for `.cfm` / `.cfc` files
- [ ] Inspect HTTP headers
- [ ] Trigger errors to identify the version

---

# Things to Remember for CPTS

- Java-based framework
- Uses `.cfm` and `.cfc`
- **8500 = ColdFusion (default)**
- `CFIDE` is the biggest giveaway
- Administrator page often leaks the version
