> Splunk is a log analytics tool used to gather, analyse and visualise data. Though not originally intended to be a SIEM tool, Splunk is often used for security monitoring and business analytics.

## Discovery/Footprinting
- In older versions, the default creds are `admin`:`changeme`
- In newer versions it is set at the time of installation. We can try common passwords though.
- Splunk Enterprise trials auto-convert to a free, unauthenticated version after 60 days. Admins often install a trial to test it, then forget about it — leaving an unauthenticated Splunk instance exposed once it converts.

- Once we log in, splunk has multiple ways of running code, such as server-side Django applications, REST endpoints, scripted inputs and alerting scripts.
- A `common method` of gaining `rce` is through use of scripted input.

# Attacking Splunk

## Abusing Built-In Functionality

- We can use [this](https://github.com/0xjpuff/reverse_shell_splunk) Splunk package to assist us. The `bin` directory in this repo has examples for [Python](https://github.com/0xjpuff/reverse_shell_splunk/blob/master/reverse_shell_splunk/bin/rev.py) and [PowerShell](https://github.com/0xjpuff/reverse_shell_splunk/blob/master/reverse_shell_splunk/bin/run.ps1).
- To achieve this, we first need to create a custom Splunk application using the following directory structure.

- `bin` directory will contain any scripts that we intend to run.
- `default` directory will have our inputs.conf file
- our reverse shell will be a PowerShell one-liner.
```python
#A simple and small reverse shell. Options and help removed to save space.

```

- The`inputs.conf` file tells Splunk which script to run and any other conditions.

**inputs.conf**
```python
[script://./bin/rev.py] 
disabled = 0 
interval = 10 
sourcetype = shell [script://.\bin\run.bat] 
disabled = 0 
sourcetype = shell 
interval = 10
```

- We need the .bat file, which will run when the application is deployed and execute the PowerShell one-liner.
```python

```
